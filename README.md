# HC孕 —— 孕产日历 Android App

将 D:\wwwroot\default 的 PHP 孕产日历系统（Web 端）以 **Kotlin** 重新实现并封装为原生 Android APK，保持原功能不变。

- 应用名：**HC孕**
- 包名：`com.hcyun.app`
- 当前版本：**1.4.13**（versionCode 173，直连 MySQL，Material 3 浅色风格：浅灰页面背景 #F2F3F5 + 纯白卡片元素 + 玫瑰粉品牌点缀；悬浮底栏图标+文字四入口、选中态图标文字变粉加粗（v1.2.23 起无选中胶囊）；v1.3.2 底栏升级为磨砂玻璃（FrostedBarBg 自绘：抓取底栏后方页面内容 1/6 降采样 + 双线性放大 + 70% 半透明白，滚动时可通过底栏模糊看到页面信息，透明 tabs 层 elevation 11dp 保证图标文字在磨砂之上），四页共用同一套 attachFloatingBar；四页滚动容器底部留白统一 40dp，内容可滚进底栏后方被磨砂显示；首页日历年月导航与网格同卡；登录页「模式切换」支持单机模式（本地 SQLite、免登录））
- 最低系统：Android 8.0（API 26）；目标 SDK 34

## 功能（与原系统保持一致）

| 模块 | 说明 |
|---|---|
| 登录 / 注册 | 直连 MySQL，bcrypt 密码校验（兼容 PHP 生成的 $2y$ 哈希）；顶部账号点击可修改本地昵称（仅本机显示，不上传服务器）；v1.2.28 起登录页「模式切换」：联网模式（数据库配置）+ 单机模式（本地 SQLite 存储、免登录直进主界面） |
| 月历视图 | 自绘月历，今天/选中为主题色描边圆角矩形指示框（宽=格宽86%、高=格高86%，自适应分辨率；今天仅描边、选中加浅粉填充；框内日期、HCG/孕酮、日程指示主题色加粗高对比）；日程指示：单日程=一个点、多日程=数量数字、有日程且有 HCG/孕酮数据=“+”号，HCG/孕酮数值直显；打开 App 默认选中今天并显示当天日程 |
| 日程管理 | 按日查看、添加（日期/阶段早中晚/标题/描述）、完成状态切换（未来日期不能标记完成）；行内无删除按钮，长按事件行或到设置页「所有事件」删除；设置页重复日程自动合并堆叠显示 |
| 孕产信息 | 末次月经 LMP 设置（日期选择 / 按孕周反推）、孕周 + 预产期 + 剩余天数 |
| 备忘录 | 列表、搜索、按日期分组、添加 / 编辑 / 删除（中文完整保存，不出现「?」） |
| 日常指标 | 每日 HCG / 孕酮录入（日历格内直显）；填写窗口两项都留空可删除该日记录；未来日期不能填写 |
| 趋势图表 | 自绘双轴图：HCG 柱状 + 孕酮折线 |
| 运行模式切换 | 登录页「模式切换」弹窗：联网模式填写数据库地址 / 端口 / 库名 / 账户 / 密码（输入框提示文字不预填默认值，支持一键"测试连接"JDBC 直连验证）；底部「单机模式」按钮一键切换本地运行（免登录，数据存 App 内置 SQLite，重启数据保留；退出自动切回联网模式） |
| 日程通知 | 首次进入 App 申请通知权限（仅通知权限，不申请日历权限）；每日 7:00/11:00/17:00 分别提醒当天 早/中/晚 未完成日程，通知标题=日程标题、内容=日程描述（粉红色调）；未完成时每 15 分钟补发一次共 4 次（15/30/45/60 分钟），4 次后停止；期间完成即停止；无该时段日程或全部完成时不打扰。**可靠性加固**：闹钟触发时应用未启动也自动创建通知渠道并通知（进程冷启动）；手机重启/时间变更/应用更新后自动重排每日闹钟（无需打开 App）；首页与设置页提供通知权限、后台精确提醒（Android 14+）、国产 ROM 自启动/后台运行引导 |

## 版本规则（约定）

> **每次代码修改发布，`versionName` 增加 0.0.1（1.1.6 → 1.1.7 → 1.1.8 …），`versionCode` 同步 +1。**
> 修改位置：`app/build.gradle` 的 `defaultConfig` 中 `versionCode` / `versionName`。

## 发布与归档规则（2026-09-16 起生效）

1. **APK 文件名带版本号**：每次发布复制为 `HC孕_v{versionName}.apk`（如 `HC孕_v1.1.9.apk`）。
2. **历史版本不删除**：所有已发布的 `HC孕_vX.Y.Z.apk` 一律保留，绝不覆盖；`HC孕.apk` 仅作为 v1.1.9 基准快照，不再随版本更新。
3. **更新日志**：每次发布后向 `更新日志.txt` 末尾追加本次版本记录（版本号 + 日期 + 变更内容）。

## 构建方法

```powershell
$env:JAVA_HOME = 'C:\buildtools\jdk\jdk-17.0.20.1+1'
C:\buildtools\gradle\gradle-8.7\bin\gradle.bat -p D:\HCYunApp assembleRelease
```

构建产物：`app\build\outputs\apk\release\app-release.apk`（release 签名）。
交付文件名：`HC孕_v{versionName}.apk`（构建后 Copy-Item 重命名，勿覆盖旧版本文件）。

签名密钥库：`hcyun.keystore`（别名 hcyun，口令 hcyun2026）——请妥善保管，后续升级必须使用同一密钥库签名。
